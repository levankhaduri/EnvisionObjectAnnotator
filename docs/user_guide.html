EnvisionObjectAnnotator

User Guide — Annotating Videos and Understanding Results

EnvisionBox project • envisionbox.org

What This Tool Does

EnvisionObjectAnnotator (EOA) uses AI to automatically track objects across a video and detect when a target object overlaps with others. The tool was developed for infant research — specifically to detect when an infant (wearing a head-mounted camera) looks at specific objects — but it can be used for any scenario where one object's overlap with others needs to be measured.

You mark objects in a single reference frame. The AI model (SAM2) then propagates those masks through the entire video, detects overlap events, and produces three output files ready for further analysis.

Step-by-Step Instructions

1. Upload Your Video

On the Config page, click the upload area and select your video file. Supported formats: .mp4, .mov, .avi, and most other common video formats.

Optionally set trim start and trim end times (in seconds) to process only a portion of the video. This can significantly reduce processing time.

Set the frame extraction rate (frames per second). A rate of 5–10 fps is typical. Higher values give finer time resolution but take longer to annotate and process.

2. Configure the Model and Detection Settings

Choose a SAM2 model based on your speed/accuracy needs:

Tiny
~40 MB
Fastest — good for testing
Small
~185 MB
Good balance
Base+
~325 MB
More accurate
Large
~900 MB
Most accurate — GPU recommended

Overlap threshold — the minimum percentage of pixel overlap between the target mask and another object's mask required to register a "looking at" event. The default is 10%. Lower values detect more (including brief) events; higher values require more sustained contact.

Bidirectional propagation — when enabled (the default), SAM2 tracks objects both forward and backward from the reference frame. More accurate but roughly doubles processing time. Disable if your reference frame is the very first frame of the video.

3. Select a Reference Frame

On the Annotation page, the first panel you see is Step 1: Select Reference Frame. Navigate through the video using the Prev/Next buttons or the frame slider until you find a good frame.

★
Use frame suggestions: Click "Suggest Optimal Frames" to have the tool automatically rank frames by sharpness and object detectability. A panel opens showing the top candidates — you can select multiple and visit them in sequence.
★
Annotating across multiple frames: When you select several suggested frames, a blue "Next Selected Frame" banner appears in the right panel. Use it to jump through each frame in sequence after annotating the previous one — useful for annotating objects that appear at different times.

Once you have navigated to your chosen frame, click "Use This Frame".

4. Add the Target Marker (Guided Flow)

After selecting a frame, the panel asks: "What would you like to do?"

  • Add Target Marker — follow the guided two-step flow below to annotate your gaze ring or other target object.
  • Skip — Add Objects Only — jump straight to the objects panel if you do not have a target marker (no ELAN or overlap output will be generated).
  • Back — Change Frame — return to the frame selection step.

Step 1: Draw a Bounding Box

The panel shows: "Click and drag on the image to draw a box around the target marker."

Click and hold on one corner of the target object, drag to the opposite corner, and release. A cyan bounding box appears around the area. If you drew it in the wrong place, click "Back — Choose Again" to cancel and return to the prompt.

Step 2: Refine with Points

After the bounding box is drawn, the panel automatically advances to Step 2: Add Points. The AI uses the box as an initial mask boundary; you can now refine it:

  • Click inside the target to place positive points (mark regions that belong to the object).
  • Switch to Negative mode and click on regions that were incorrectly included (e.g. the hand of an experimenter near the gaze ring).
  • Use Test Mask to preview the AI's mask in a pop-up overlay.
  • Press Undo to remove the last point. Press Undo again when no points remain to go back to the bounding box step.

When the mask looks correct, click "Done — Save Target".

5. Add Objects to Track

After saving the target, the full Objects panel opens. For each additional object you want to track:

  1. Type a name in the "Object name" field (e.g. cup, toy_car, face).
  2. Optionally tick "Mark as target" if this object should also act as a gaze source (rarely needed — you normally only have one target).
  3. Click Add. The object appears in the list and becomes the active selection.
  4. Click directly on the object in the frame to place positive points. Switch to Negative mode to exclude regions.
  5. Click Save (or press Enter) to confirm the annotation.
  6. Repeat for each additional object.
⚠
If no object with "target" in its name is annotated, the tool will track objects and export the annotated video and CSV, but will not generate an ELAN file.

6. Start Processing

Once at least one object is saved, the Process button in the top-right header becomes active. Click it. SAM2 propagates masks through every frame and detects overlap events. On a modern GPU, a 10-second video at 5 fps takes 10–30 seconds. On CPU only, this may take several minutes.

Progress stages shown on screen:

  • Processing — SAM2 propagating masks frame by frame
  • Saving — rendering the annotated video and writing output files
  • Completed — all outputs are ready for download
⚠
Do not close the browser tab during processing. The backend continues even if the tab is hidden, but keeping it open ensures the result files are available for download.

7. Download Results

The Results page shows a summary of detected overlap events and a download button for all output files as a single ZIP archive. The CSV export is generated asynchronously and may appear a few seconds after the other files.

Understanding the Outputs

🎥
Annotated Video
.mp4

The original video with colored mask overlays for each object. Overlap events are shown as on-screen labels ("Looking at: toy").

📊
CSV Export
.csv

One row per frame per object. Contains bounding box coordinates, centroid position, mask area, and overlap status for every tracked object.

📋
ELAN File
.eaf

Time-aligned annotation file for ELAN software. Contains "Looking at: [object]" events on separate tiers for each tracked object.

The Annotated Video

Each tracked object is shown with a semi-transparent colored mask. When the target overlaps an object, an on-screen label appears indicating the event. This is useful for a quick visual sanity check of the detection results.

The CSV File

The CSV has one row per frame per object. Key columns:

ColumnDescription
frame_idxFrame number (0-based)
obj_nameObject name as you entered it
bbox_x, bbox_y, bbox_w, bbox_hBounding box (pixels, relative to frame)
centroid_x, centroid_yMask centroid position
mask_areaNumber of pixels in the mask
overlap_pctPercentage overlap with the target (0–100)
is_looking_at1 if overlap exceeds the threshold, 0 otherwise

You can open the CSV in Excel, R, or Python for further analysis. The frame index can be converted to timestamps by dividing by the extraction frame rate.

The ELAN File

ℹ
Open the downloaded .eaf file directly in ELAN. Each tracked object appears as a separate annotation tier; overlap events are labelled "Looking at: [object]" with millisecond-precision timestamps aligned to the original video.

The ELAN file (.eaf) can be opened directly in ELAN (free software from the Max Planck Institute). It contains one annotation tier per tracked object, with annotations spanning the time ranges where the target was overlapping that object.

Annotations are labelled "Looking at: [object name]". The timing is in milliseconds and is aligned to the original video timeline, accounting for any trim offset you applied.

ℹ
The ELAN file is only generated when at least one target object is annotated and at least one overlap event is detected. If no events were detected, check that your overlap threshold is not set too high, or that the target and objects were actually close in the video.

Tips for Better Results

Choosing the right reference frame

  • Use a frame where all objects you want to track are clearly visible and well-lit.
  • Avoid frames with heavy motion blur.
  • If the target object (e.g. gaze ring) is only visible for part of the video, choose a frame near the middle of that period and enable bidirectional propagation.

Getting clean masks

  • For the target marker, always use the bounding box first — the guided flow does this automatically. The box gives SAM2 a tight region to work within before you place points.
  • For other objects, start with one positive point at the center of the object and preview with "Test Mask" before saving.
  • If the mask bleeds onto neighboring regions, add negative points on those regions.
  • A mask that covers ~80–90% of the object is usually sufficient — perfect coverage is not required.

Adjusting the overlap threshold

  • 10% (default) — suitable for most scenarios where the target is small relative to the objects it overlaps.
  • Lower (e.g. 5%) — detect more events including brief or partial overlaps. More false positives are possible.
  • Higher (e.g. 25–50%) — only register events where the target substantially overlaps the object. Reduces false positives but may miss brief events.

Managing long videos

  • Use the trim start/end fields to process only the relevant portion of the video.
  • Use the Tiny or Small SAM2 model for a first pass, then re-run with a larger model if accuracy is insufficient.
  • On CPU-only systems, a 1-minute video at 5 fps (300 frames) may take 5–15 minutes to process.

Frequently Asked Questions

Can I annotate more than one "target" object?

Only one target object is supported per session. If you name multiple objects with "target" in the name, only the first one will be used as the primary overlap source. If you need to track multiple gaze sources, process the video multiple times with different target annotations.

What if the AI tracks the wrong object after a few frames?

SAM2 propagation can drift when objects are occluded, move out of frame, or look very similar to the background. To improve tracking:

  • Add negative points to exclude confusing background regions at annotation time.
  • Use a larger SAM2 model (Base+ or Large).
  • Enable bidirectional propagation — it can correct drift on both sides of the reference frame.
  • Choose a reference frame closer to the part of the video where tracking is most critical.
The ELAN file is missing — why?

The ELAN file is only created when:

  1. At least one object with "target" in its name was annotated.
  2. At least one overlap event was detected during processing.

If the file is missing, check (1) that your target object name contains the word "target" and (2) that the overlap threshold is not set higher than the actual overlap in the video.

How do I import the ELAN file into ELAN software?

Open ELAN (free download at archive.mpi.nl/tla/elan). Go to File → Open and select the .eaf file. The software will prompt you to locate the associated video file — browse to the original video file. The annotations will then appear on the timeline aligned with the video.

Can I re-annotate and reprocess the same video?

Yes. Start a new session for each annotation pass. Sessions are independent and stored separately on your local machine. Previous sessions do not affect new ones.

The CSV export takes a long time to appear in the results

The CSV and masks JSON are generated asynchronously after the main processing pipeline completes. The Results page may show the annotated video and ELAN file before the CSV is ready. Wait a few seconds and refresh the page — the CSV download link will appear once the export is complete.

Data and Privacy

EnvisionObjectAnnotator runs entirely on your local machine. No video data, annotations, or results are sent to any external server. All processing is done by the backend running on your computer (or HPC cluster). This makes the tool suitable for working with sensitive or proprietary video data, including infant recordings subject to data privacy regulations.
