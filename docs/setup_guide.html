EnvisionObjectAnnotator

Setup Guide — Installing and Starting the Application

EnvisionBox project • envisionbox.org

Before You Begin

This guide walks you through installing EnvisionObjectAnnotator from scratch on a Windows, Mac, or Linux computer. No programming experience is needed — just follow each step in order.

ℹ
Time required: 20–30 minutes, mostly waiting for downloads. The model files are approximately 1.5 GB total.

Step 1 — Install Prerequisites

The tool needs four software packages installed on your system. Install each one before continuing.

Python
Version 3.10 or newer

Download from python.org.

Important (Windows): On the first installer screen, check the box labelled "Add Python to PATH" before clicking Install Now.
python --version
Node.js
Version 18 LTS or newer

Download from nodejs.org. Choose the LTS (Long Term Support) version.

node --version
Git
Any recent version

Download from git-scm.com. Use the default options during installation.

git --version
FFmpeg
Any recent version

Download from ffmpeg.org. After installing on Windows, add it to your system PATH.

ffmpeg -version

Verify everything is installed

Open a terminal (see Step 2 for how) and run each command. Each should print a version number, not an error.

python --version
node --version
git --version
ffmpeg -version
⚠
If any command says "not found" or "not recognized", that program is not installed correctly. Re-install it and make sure to add it to PATH when prompted.

Step 2 — Open a Terminal

Windows

Open the Start menu, search for PowerShell, and open it.

Then run this one-time command to allow setup scripts to run (you only need to do this once per computer):

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

When prompted, type Y and press Enter.

Mac / Linux

Open the Terminal application from your Applications folder or app launcher.

Step 3 — Download the Tool

In your terminal, run:

git clone https://github.com/levankhaduri/EnvisionObjectAnnotator.git
cd EnvisionObjectAnnotator

This creates a folder called EnvisionObjectAnnotator containing all the tool's files.

Step 4 — Run the Setup Script

⚠
Leave the terminal open and do not close it. The setup downloads ~1.5 GB of AI model files and installs all dependencies. This can take 10–20 minutes. Wait until you see "Setup Complete!" before continuing.
Windows
.\setup.ps1
Mac / Linux
chmod +x setup.sh && ./setup.sh

The setup script will:

  • Create a Python virtual environment
  • Install all Python packages
  • Download SAM2 and its model checkpoints (~1.4 GB)
  • Install all frontend packages
  • Verify your GPU setup (if available)

Step 5 — Start the Application

Windows
.\run.ps1
Mac / Linux
./run.sh

Two background processes start: the backend API (port 8000) and the frontend (port 5173). Your browser should open automatically. If it does not, open:

http://localhost:5173
✓
You should see the EnvisionObjectAnnotator home page with a green "Backend connected" indicator. The tool is ready to use.

Stopping the Application

To stop the servers:

  • Windows: Close the two PowerShell windows that opened (one for the backend, one for the frontend).
  • Mac/Linux: Press Ctrl+C in the terminal where you ran ./run.sh.

Subsequent Sessions

After the first-time setup, you only need to run the start script each time you want to use the tool:

# Windows
.\run.ps1

# Mac/Linux
./run.sh

You do not need to run setup.ps1 / setup.sh again unless you reinstall or update the tool.

Troubleshooting

The browser shows "Cannot connect to backend" or a blank page

The backend server may not have started yet. Wait 10–15 seconds and refresh the page. If the problem persists:

  • Check that port 8000 is not used by another program.
  • On Windows, look for the PowerShell window titled "backend" — it may show an error message.
  • Try restarting: close all related windows and run .\run.ps1 again.
Setup fails with "pip: command not found" or Python errors

Python was not added to PATH during installation. Re-install Python from python.org and on the first screen tick the "Add Python to PATH" checkbox before clicking Install Now. Then close and reopen the terminal and run .\setup.ps1 again.

Setup fails at the SAM2 download step (network error or timeout)

The SAM2 model files are hosted by Meta and may be slow on some networks. Try:

  • Running .\setup.ps1 again — it will resume from where it stopped.
  • Switching to a faster or less restricted network connection.
  • Running during off-peak hours if you are on a shared network.
"ffmpeg: command not found" during video extraction

FFmpeg is installed but not on PATH. On Windows, follow the instructions at wikihow.com/Install-FFmpeg-on-Windows to add FFmpeg to your system PATH. Then close and reopen PowerShell and try again.

Processing is very slow — no GPU detected

The tool works on CPU but is significantly slower. GPU acceleration requires an NVIDIA GPU with CUDA support. The home page shows a GPU status indicator — if it shows "CPU only", processing a 30-second video may take several minutes instead of seconds. This is normal and the results will be the same quality.

If you have an NVIDIA GPU but it is not detected, check that you have the latest NVIDIA drivers installed.

Windows: "running scripts is disabled" error

You need to allow script execution. In PowerShell, run:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Type Y when prompted, then try running .\setup.ps1 again.

Linux / HPC: running inside a Singularity container

The tool can be deployed in a Singularity container. The SAM2 model configuration is loaded using relative paths, so the tool does not require any path adjustments inside the container. Make sure:

  • The container includes Python 3.10+, Node.js 18+, FFmpeg, and CUDA libraries (if GPU is available).
  • The EnvisionObjectAnnotator directory is mounted inside the container.
  • Run the backend with uvicorn app.main:app --host 0.0.0.0 --port 8000 from within backend/.
